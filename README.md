# Homebrew Tap for dastrobu

This is a [Homebrew](https://brew.sh) tap for my projects.

## Installation

```bash
brew tap dastrobu/tap
```

## Available Formulae

### mail-mcp

MCP server providing programmatic access to macOS Mail.app.

```bash
brew install mail-mcp
```

See the [mail-mcp repository](https://github.com/dastrobu/mail-mcp) for more information.

### pdf-blick

MCP server for fast, secure PDF inspection and page rendering.

```bash
brew install pdf-blick
```

See the [pdf-blick repository](https://github.com/dastrobu/pdf-blick) for more information.

## Updating

```bash
brew update
brew upgrade <formula>
```

## Uninstalling

```bash
brew uninstall <formula>
brew untap dastrobu/tap
```

## About

This tap is automatically updated by [GoReleaser](https://goreleaser.com/) when new releases are published.

The formula files are located in the `Formula/` directory.
